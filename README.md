# Spark Team

Build a full-stack real-time collaboration and chat app for multidisciplinary university project teams and hackathons. Set up Lovable Cloud backend with Supabase Auth, PostgreSQL, and Realtime for profiles (with discipline role badges), channels, messages with code snippets and markdown, tasks (Kanban board), and project milestones with a countdown timer and deliverables checklist. Use a dark developer-focused UI aesthetic inspired by Linear and Discord.

This project was built with [Lovable](https://lovable.dev).

